# 失敗台帳

Claude が外したことを 1 件ずつ残す。直近 8 件はセッション開始時にフックが読み込ませる。追記だけする。
書式: `## F-番号 日付 — ひとこと` ／ 起きたこと ／ 原因 ／ 再発防止（どのファイル・どの検査に入れたか）。
起きていないことを書かない。分からない点は「不明」と書く。

## F-01 2026-10-14 — 他人のリポジトリへ push した
- 起きたこと: YASU のリポジトリに営業資料のブランチを push した。
- 原因: 記録なし（基盤スキルに残っているのは出来事と再発防止だけ）。
- 再発防止: 基盤スキルの禁則「他人のリポジトリには一切 push しない」。

## F-02 2026-10-16 — 確認なしにメールを送った
- 起きたこと: 鍵山の Gmail から GitHub サポートへ、確認なしに送信した。
- 原因: 記録なし（基盤スキルに残っているのは出来事と再発防止だけ）。
- 再発防止: 基盤スキルの禁則「外に出る操作は、その操作ごとの明示の一言まで実行しない」。台帳 O-07。

## F-03 2026-11-10 — 直す箇所の取りこぼしと、頼まれていない箇所の破壊（鍵山の報告）
- 起きたこと: 鍵山の報告。「直しているところと直していないところがある」「ここを直してと言うと平気で他を壊す」「やるなと言ったことをやる」「以前の指示を覚えていない」。個別の発生箇所はこの台帳に未記録（不明）。次に起きたら箇所つきで 1 件ずつ足す。
- 原因: 確定していない。仕組みの側で言えるのは、指示が会話の中にしかなく、圧縮や別セッションで消えていたこと、終了前に差分と要件を突き合わせる段がなかったこと。
- 再発防止: 台帳 O-01〜O-05。`tools/claude_guard.py`（開始時の読み込み、毎回の型、終了前の自己監査）、`tools/check_invariants.py`（回帰検査）、`critical-reviewer`（他者レビュー）。

## F-04 2026-11-18 — URL だけ渡されたのに、公開先を確かめずに「影響なし」と書き、推しを出さず聞き返して止まった
- 起きたこと: 鍵山が Cloudflare の更新記事（新しい CLI の 1.0 候補版）の URL を 1 本渡した。Claude は要約、「いまは影響なし」、使い道の候補 1 つ（台帳との照合は未確認と明記）を書き、推しを出さずに、この記事で何をしたいかを聞き返して終えた。鍵山「何をしたいかではなく、何ができて鍵山の価値を上げるにはどうしたらいいのか？」。さらに「サイトは GitHub Pages なので」は誤りだった。「いまは影響なし」は公開先を確かめずに言い切ったもので、影響の有無は不明（Cloudflare 側への出し方はこのリポジトリに記録がない）。このリポジトリの `index.html` は `https://kaginight.pages.dev/`（Cloudflare 側）への転送で（commit 8f36f76、回帰検査の「2026-10-17 の決定」）、公開中の `/play/` のページは Cloudflare の Workers（`kagi-count` と `kagi-rank`）を参照している。他者レビューの指摘で分かった。
- 原因: 検索した語が `cloudflare|wrangler` だけで、`pages.dev` を見なかった。`index.html` と回帰検査を開かずに公開先を言い切った。基盤スキルと `docs/IDEA_LEDGER.md` を読む前に答え、基盤スキルの「提案のしかた」（鍵山の値段を上げるかで選ぶ、推し 1 つと理由 2 行）を当てなかった。
- 再発防止: URL・記事・資料だけを渡されたときは、聞き返す前に、基盤スキルと `docs/IDEA_LEDGER.md` を読み、`index.html` と公開中のページで公開先を確かめてから、「何ができるか」と「鍵山の価値を上げる推し 1 つ」まで出す。聞くのは鍵山にしか決められないことだけ（例: アカウント作成、外に出る操作、禁則に触れそうなとき）。同日、鍵山の「これは全てのチャットにいえること」を受けて、絶対指示の台帳 O-09 に入れた。回帰検査が見るのは O-09 とこの項目が残っていることだけで、守られたかどうかは機械では確かめられない。
