# 失敗台帳

Claude が外したことを 1 件ずつ残す。直近 8 件はセッション開始時にフックが読み込ませる。追記だけする。
書式: `## F-番号 日付 — ひとこと` ／ 起きたこと ／ 原因 ／ 再発防止（どのファイル・どの検査に入れたか）。
起きていないことを書かない。分からない点は「不明」と書く。

## F-01 2026-10-14 — 他人のリポジトリへ push した
- 起きたこと: YASU のリポジトリに営業資料のブランチを push した。
- 原因: 記録なし（基盤スキルに残っているのは出来事と再発防止だけ）。
- 再発防止: 基盤スキルの禁則「他人のリポジトリには一切 push しない」。

## F-02 2026-10-16 — 確認なしにメールを送った
- 起きたこと: 鍵山の Gmail から GitHub サポートへ、確認なしに送信した。
- 原因: 記録なし（基盤スキルに残っているのは出来事と再発防止だけ）。
- 再発防止: 基盤スキルの禁則「外に出る操作は、その操作ごとの明示の一言まで実行しない」。台帳 O-07。

## F-03 2026-11-10 — 直す箇所の取りこぼしと、頼まれていない箇所の破壊（鍵山の報告）
- 起きたこと: 鍵山の報告。「直しているところと直していないところがある」「ここを直してと言うと平気で他を壊す」「やるなと言ったことをやる」「以前の指示を覚えていない」。個別の発生箇所はこの台帳に未記録（不明）。次に起きたら箇所つきで 1 件ずつ足す。
- 原因: 確定していない。仕組みの側で言えるのは、指示が会話の中にしかなく、圧縮や別セッションで消えていたこと、終了前に差分と要件を突き合わせる段がなかったこと。
- 再発防止: 台帳 O-01〜O-05。`tools/claude_guard.py`（開始時の読み込み、毎回の型、終了前の自己監査）、`tools/check_invariants.py`（回帰検査）、`critical-reviewer`（他者レビュー）。
