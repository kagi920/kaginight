# 鍵山のサブカル — 最初のアイデアの整理 v1（2026-10-15）

鍵山が口にしたアイデアを、出た順でなく**構造**で並べ直したもの。これが正本。作る前に必ずここを読む。

## 1. 決まっていること（鍵山の言葉から）
| # | 決定 | 出どころ |
|---|---|---|
| D1 | **基本のクラゲは壊さない。モチーフを壊したらダメ。** いつもは元の HP のまま | 「基本のクラゲはそのままいてよ」「元の内容をしっかり」 |
| D2 | サブカルは**演出・見せ方・デザイン**で出す。**言葉は足さない**（HP にある文だけ） | 「文章や言葉は決めてある。中身だけに」 |
| D3 | 方向は**アートポップ寄りのサブカル**。昭和・アングラ・アーバンギャルドには寄せない | 「アートポップサブカル」「アーバンギャルドに寄せないで」 |
| D4 | **塩田千春の要素**。ただし糸や鍵を画面に貼るのではなく、**クラゲ自身が糸になる・鍵になる** | 「糸のクラゲが出るとか、鍵のクラゲが出るとか」 |

| D7 | 度合いは 120% から引き算で決める（画像で比べる） | 「120% を見てから引き算」 |

## 2. 禁止（鍵山が「一番嫌い」と言ったもの）
- **モチーフを画面に貼ること**（鍵の絵、赤い糸の線、帯、判子、電光掲示、網点、走査線）。「ただ鍵と糸を出しただけ」は最悪。
- 昭和・看板・アングラ演劇ポスターの装置。
- 新しい言葉、新しい色面、常時表示の装飾。
- 主役のクラゲの形・動き・音を壊すこと（素材が変わっても、形と動きは同じ）。

## 3. 基礎（なぜ「クラゲ自身が変わる」が正しいか）
- **素材置換**は美術の古典的な方法。同じ形を別の物質で作り直す（アルチンボルドの果物の肖像、塩田千春の糸で包んだ物、草間彌生の水玉で覆った物）。モチーフを「貼る」のではなく「成る」。
- 鍵山の美学（**物化・質量への憧憬・変容**）と一致する。質量のないクラゲが、糸（繊維）や鍵（金属）という質量を帯びる。
- サブカルの本質は**間接性**。鍵を見せるのではなく、クラゲが鍵でできていることに気づく。
- 根拠の資料: `KAGI_SUBCUL_PRINCIPLES_v1.md`（P1〜P7）。

## 4. 実装済み（v26）
- 3 回叩く → 夜が半秒息を止める → 主役の素材が変わる: **元 → 赤い糸 → 緑の糸の鍵 → 塵 → 元**（鍵山の指定: 糸は赤、鍵は緑の糸）。
- 赤い糸のクラゲ: 同じ傘・触手・口腕を赤い糸で編み直す。
- 緑の糸の鍵のクラゲ: 点のひとつひとつが緑の糸で描いた小さな鍵になる。拍動で少し揺れる。
- 塵のクラゲ: 解けて漂う。
- 群れ・UI・音・文章は不変。画面に何も貼らない。色を足さない。
- 一分の不在（v22）も残す。

## 5. 次に足せる仕掛け（すべて「クラゲ自身が変わる」）
| 案 | 中身 | 根拠 |
