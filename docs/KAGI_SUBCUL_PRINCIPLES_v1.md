- 参照を**モチーフ**として引用した（赤い糸・鍵を画面に貼った）。専門家はモチーフでなく**方法**を取る。塩田千春の本質は糸でも鍵でもなく「不在のなかの存在」（下記）。

## 2. サブカルの本質（参照から）
- 定義: 主流文化に対する一部の集団の文化（リースマン 1950）。日本では「わかる人にはわかる」符号の文化（[weblio 副文化](https://www.weblio.jp/content/副文化)）。
- 90 年代のサブカル誌 Quick Japan（1993 年創刊）の文脈では「好きでないものを見つけ、好きになり、快楽に転化する」「あらゆるコンテンツに価値を見出す選択的な感性」（岡島紳士、[Tokyo Otaku Mode](https://otakumode.com/news/55b7064280b64acf398f6eb5)）。
- 塩田千春の本質: 場所や物に残った痕跡を「記憶」ととらえ「**不在のなかの存在**」を扱う。記憶・不安・夢・沈黙という形のないもの。他者との「つながり」（[大阪中之島美術館 2024](https://nakka-art.jp/wp10/wp-content/uploads/2024/04/20240409_pressrelease_shiotachiharu.pdf)、[琉球新報](https://ryukyushimpo.jp/news/entry-1421146.html)）。
- 落合陽一の計算機自然: 境界領域における**物化と変換**、**質量への憧憬**、「汎神化した計算機による侘と寂」（[美術手帖](https://bijutsutecho.com/magazine/news/headline/21870)、[落合陽一 展覧会](https://yoichiochiai.com/exhibition/digital-nature-existence-from-null-to-null/)）。
- Web の作法: 「less is more」。平凡に見える画面の裏に仕掛けを隠す（Red Dot 受賞の Pete Philly サイト、[red-dot.org](https://red-dot.org/project/pete-philly-open-loops-17954)）。隠し層・合言葉で入る裏サイト（Bring Me the Horizon の例）。

→ 共通する本質は **間接性・符号・選別**。直接見せない。気づいた人だけが入れる。ズレと違和感を愛でる。真剣な遊び。

## 3. 重要ポイント（設計原則。鍵山が丸と×をつける）
| # | 原則 | 画面ではこうなる | 逆（やらない） |
|---|---|---|---|
| P1 | **直接言わない** | 概念は振る舞いで示す。モチーフを貼らない | 赤い糸・鍵・帯・判子を描く |
| P2 | **気づく人だけ** | 一見いつもと同じ。注意深い人だけが変化に気づく。隠し扉、条件つきの振る舞い | 常時表示、点滅、告知 |
| P3 | **違和感は一つ、小さく** | 正しい絵の中の一箇所だけが狂う | 全体を汚す、網点・走査線 |
| P4 | **身体と実打**（ハードコア由来） | 叩くと世界が本当に変わる。反応は誠実で重い | 飾りのアニメーション |
| P5 | **不在の気配**（塩田から取る方法） | いないもの・過ぎたもの（前回の夜、今いない人、消えたクラゲ）の痕跡 | 糸や鍵の図解 |
| P6 | **質量と変換、欠け**（計算機自然から） | 音→光→言葉→触覚の変換。経年・静寂・欠け | 完璧に磨いた UI |
| P7 | **夜と時間**（KAGI NIGHT） | 時刻で振る舞いが変わる。深夜だけ、毎時 1 分だけ | 時間と無関係な装飾 |

## 4. 原則から出る演出の候補（まだ作らない。概念だけ）
| 案 | 中身 | 原則 |
|---|---|---|
| a 一分の不在 | 毎時 1 分間だけ主役のクラゲがいなくなり、その場所に塵のような残り香だけが漂う。戻るときに一打 | P2 P5 P7 |
| b 叩いた痕 | 自分が叩いた一打が消えず、小さな痕として数時間残る。自分の端末だけに見える | P4 P5 |
| c 深夜の静寂 | 2〜4 時だけ、音のパッドが消えてティックだけになり、水が止まる | P6 P7 |
| d 鍵穴 | 画面のどこかに 1px の鍵穴。見つけて長押しした人だけが KAGI ROOM の入口に出会う | P2 鍵 |
| e ズレ | 一時間に一度、群れの一体だけが逆さに泳ぐ | P3 |
| f 欠け | 点群の一部が欠けていて、欠けの形が鍵の影になっている。言われなければ気づかない | P1 P6 鍵 |

推し: 普段は **a＋f＋d**（30% 相当。何も足さず、欠けと不在と隠し扉だけ）。ライブの夜だけ **c＋e** を足す（120% 相当）。どれも言葉・色・装飾を足さない。
