### Inferences
- 「信頼性」は (a) 査読付き発表（NIME/IEEE VR Demo が最短）、(b) 顕彰（Prix Ars・NEWVIEW）、(c) 公開リポジトリ+定量ログ（レイテンシ、30Hz OSC、観客数等）、(d) 東京拠点の継続的ライブ実績（KAGI NIGHT）の組合せで作るのが、先行事例（AirSticks）と各要項から読み取れる現実的な経路。ORCID と GitHub は投稿時の著者情報として必要十分で、無所属を妨げる規定は本調査で確認した要項には見当たらなかった。
