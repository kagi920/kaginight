# 1990年代スーパーファミコンRPGテレビCM 映像文法・合成・時間比率 総合仕様書

Version: 1.0 / 2026-11-10
主対象: 『ファイナルファンタジーVI』（1994）、『テイルズ オブ ファンタジア』（1995/SFC版）、『魍魎戦記MADARA2』（1993）、『エストポリス伝記』（1993）／『エストポリス伝記II』（1995）
使用目的: 歴史資料の整理、90年代RPGテレビCMの撮影・編集・合成表現の分析、および新規オリジナルCM制作の技術仕様化。

> **証拠境界:** 本書では当時の映像を収録した公開アーカイブ、メーカーの現存する公式資料、公開された制作・楽曲情報、関連する技術規格を照合した。ただし、この調査環境ではYouTubeの動画フレーム自体をダウンロードしてフレーム単位で実測できない。よって**各作品の「実写何％・ゲーム映像何％」という実測値は現時点で未確定**。後述の比率モデル、ショット表、秒数表の数字は**新規制作のための設計推奨値**であり、1990年代の放送素材から測定した統計ではない。

## 0. エグゼクティブ・サマリー

1. 90年代SFCのRPG CMには、ゲーム画面を単に見せるだけでなく、「現実と異世界の衝突」「俳優による物語の代理表現」「ゲーム画面の高速モンタージュ」「主題歌で引っ張る印象広告」など複数の文法があった。
2. 『FFVI』1994年CMの象徴は、渋谷スクランブル交差点という実在空間に、ティナと魔導アーマーを出現させる実写・合成演出。少なくとも同作CMを一本の均質な形式として集計してはいけない。実写合成型とゲーム画面中心型の異なる版が報告されている。
3. 『テイルズ オブ ファンタジア』のSFC版は1995年、PS版は1998年。ナムコ公式サイトに存在する雪の都会で少女が登場するCMは1998年PS版のCMであり、1995年SFC版の描写へ流用してはいけない。
4. 『MADARA2』はCMアーカイブとCMソングを確認できる。1980〜90年代の漫画・音楽・ゲームを横断する世界観を参照軸とするが、1993年CMの具体的なカット割りは未実測。
5. 『エストポリス伝記II』のCMにはマキシムとセレナが名前を呼び合い、引き離される演出があったという二次資料がある。また1994年末に予定された発売の告知版と1995年2月版の変更が指摘されている。原版照合が必要。
6. 実写／ゲーム比率を分析する際は「秒数」と「画面内面積」を分け、実写とゲームが同時に存在するフレームを二重計上しない集計方法を用いる。

## 2. 作品別・映像演出の解析

### 2.1 『FFVI』—「現実へ侵入する異世界」

確認された事実（A〜C）
- SFC版発売日は1994年4月2日。
- 1994年のテレビCMには、実写の渋谷スクランブル交差点にティナと魔導アーマーが現れる印象的な場面がある。実写と合成の結合という特徴は、複数の独立した資料が記述する。
- 当時の人物・都市の写実性と、ゲーム世界の「魔導アーマー」の非日常性を対照させる。
- 別系統のゲーム画面紹介を中心としたCM版が存在したとする記録がある。後者のBGMを「ROAMING SHEEP」とする資料がある。
- 実写合成版は15秒と30秒のバージョンがあったとする音楽資料がある。

構造的解釈（D）
1. 都市空間を最初に提示 → 観客が『現実』の縮尺を理解する。
2. そこに異世界の人物／物体を置く → 説明ではなく衝突の視覚効果が生まれる。
3. 事件の説明を省き、音楽・存在感を優先 → RPGの長い物語を短時間で暗示する。
4. ゲーム画面に橋渡しすることで『実際に遊べる世界』へ帰着させる。ただし版によってゲーム画面の有無・尺は変わり得る。

合成検査点: 影の方向、路面との接地、通行人との前後関係、カメラ運動、視線、実写と造形物の粒状感、ローカルコントラスト、テロップと背景の輝度差。

再制作への適用: ビル街／公園／駅をライブアクションで撮影し、平面ドットキャラクターではなく『キャラクターの現実版』または巨大な立体小道具をまず世界へ置き、後半でドット絵へ転換する。

### 2.2 『テイルズ オブ ファンタジア』（SFC・1995）—「主題歌と物語の感情的入口」

確認された事実（A〜C）
- 第1作SFC版は1995年12月15日発売。
- SFC版の主題歌「夢は終わらない ～こぼれ落ちる時の雫～」は吉田由香里歌唱。歌唱入りOPは当時のROMカートリッジ作品として特徴的。
- SFC版CMの再公開資料は存在するが、本調査ではショット構成と実写合成の有無を画面レベルで確認できていない。
- 1998年PS版と混同厳禁: ナムコ公式のPS版CMページには雪の降る都会、3人の中学生、15秒、宮崎あおいらの出演、よーみ歌唱と明記されている。これは1995年SFC版の事実ではない。

構造的解釈（D）
主題歌が明瞭なRPGは、ゲームプレイの機能説明より『物語へ入る感情』の宣伝が成立しやすい。歌を連続再生し、画面を物語の断片でつなぐアプローチを本書では「楽曲主導のドラマ型」と呼ぶ。ただし、SFC版CMの実際のショット割りをそう断定するものではない。

再制作への適用: 歌の冒頭／フックを切らず、人物の表情→世界観を示すイラスト／ゲーム画面→タイトルへ編集する。PS版の雪やキャスティングをSFC版資料として使用しない。

### 2.3 『魍魎戦記MADARA2』—「漫画・音楽・RPGのメディア横断」

確認された事実（B〜C）
- 1993年7月16日、コナミ発売。
- 1990〜1993年の『魍魎戦記マダラ』CM集には『MADARA2』を含むと明記されている。
- 1993年発売の『MADARA2 サウンド・ファンタジア』には、國府田マリ子が歌ったCMソングが収録されているとの販売資料あり。曲目「ライツ～遥かな旅立ち」の記載もある。
- CM集の投稿説明には「田島昭宇」出演者名があるが、1990年FC版と1993年SFC版のどちらの映像に出演したかを、このリストだけで断定できない。FC版広告への出演を扱った二次資料もある。

構造的解釈（D）
独特の漫画線画、呪術・古代的モチーフ、音楽的な高揚を組み合わせると、直截なゲーム画面説明を減らしても世界観を伝えられる。ただし史実としてのCMカット割りは要原版確認。

再制作への適用: 逆光シルエット、実物の仮面や布、古い紙の平面絵、低解像度のゲーム映像を「同一カット内」ではなく「音と形の類似」で接続する。元作品のキャラクター造形や楽曲の無断複製は行わない。

### 2.4 『エストポリス伝記』『エストポリス伝記II』—「関係性を短尺ドラマ化」

確認された事実（B〜C）
- 第1作（1993年6月25日）と第2作（1995年2月24日）には、それぞれCMアーカイブがある。
- 『II』ではマキシムとセレナが名を呼び合いながら引き離される演出があったとの二次資料がある。
- 『II』の発売予定は当初1994年12月と告知され、1995年2月版で演出が多少変わったと指摘されている。初期版と修正版を分けて分析する必要がある。

構造的解釈（D）
相互に呼び合う2人、遮る障害、断絶の瞬間を使うと、RPGの複雑な世界観を感情関係という最小単位に圧縮できる。独創的なのは戦闘画面ではなく「誰かに会いたい」という動機を先に置くこと。

再制作への適用: 左右に別れた人物、風・布・光・合成レイヤーによる隔たり、近景と遠景のズレ、クローズアップを用い、最後にゲーム画面とタイトルで意味を回収する。

## 3. マクロ分析：時代と演出の構造

### 3.1 六つのCM類型

|類型             |中心情報            |実写／ゲームの関係           |適する目的             |
|---------------|----------------|--------------------|------------------|
|A. 現実侵入型       |日常に現れる非日常       |実写プレート＋人物／造形物／VFXの合成|FFVI風の強い一撃        |
|B. 実写ドラマ型      |登場人物の感情・対立      |俳優／ロケ／小道具が物語を代理     |エストポリスIIに関連する方向   |
|C. 楽曲主導型       |主題歌による記憶        |歌を軸に実写・絵・ゲームを連鎖     |テイルズ的な感情訴求の設計     |
|D. ゲーム画面モンタージュ型|戦闘・風景・システム      |フルフレーム／窓枠付きゲーム画面    |ゲーム内容の証明          |
|E. 紙媒体・イラスト移植型 |漫画・絵画・キャラクターデザイン|静止画をパン、ズーム、レイヤー化    |MADARA2の世界観を参照した設計|
|F. 商品パッケージ型    |タイトル・発売日・機種     |最終数秒を文字と製品に集中       |あらゆる類型の終端         |

これらは本書で定義した分析類型であり、当時の広告業界による正式な分類を引用したものではない。

### 3.2 実写が強い理由（分析仮説）
- ドット絵を実写の記号へ『翻訳』することで、テレビを観ているゲーム未経験者にも世界観を伝えられる。
- 背景に日常風景を使うと、異世界要素に強烈なスケール感が生じる。
- 15秒では長い設定説明より、場面ひとつ・感情ひとつ・歌のフレーズひとつが認知的に扱いやすい。
- ゲーム画面を見せる広告と、ゲームを「体験したくさせる」広告は目的が異なる。両方の比率を取らなければ評価は偏る。

### 3.3 周辺標本
比較用に1994・1995年のCM集には『クロノ・トリガー』『聖剣伝説3』『ミスティックアーク』『天地創造』『タクティクスオウガ』『ロマンシング サ・ガ3』などが収録タイトルとして列挙されている。CM中の合成手法・実写有無は未個別検証であり、タイトルが含まれることを超える主張をしない。

## 4. 「実写とゲームの比率」の測定仕様

### 4.1 二層構造で記録する

第1層：主成分（1フレームにつき原則1分類）
- L = 実写主体（俳優・街・小道具、特撮ミニチュアを含む）
- G = ゲーム映像主体（実ゲーム画面）
- I = イラスト・漫画・手描きアニメ主体
- T = タイトル・商品・発売日・ロゴ主体
- X = その他／判定不能

第2層：同時に存在する要素（複数タグ可）
- overlay_game = 実写上にゲーム画面が同時表示
- overlay_art = 実写上に絵／CG／特撮物が同時表示
- composite_3d = 立体的な造形物・人物を背景に合成
- picture_in_picture = 額縁／小窓／テレビ画面内にゲーム表示
- text_over_image = フレーム全面ではないテロップ重畳
- vfx_transition = ディゾルブ／ワイプ／キーイング等の過渡表示

### 4.2 数値の定義

CM全長を T 秒、各フレーム時間を Δt とする。
- 主成分時間比率: R_L = Σ[primary=L]Δt / T、R_G 等も同様。R_L+R_G+R_I+R_T+R_X=1。
- 実写存在時間比率: P_L = Σ[live_present=true]Δt / T。実写が隅に少しでもあれば数えるので上記 R_L とは異なる。
- 同時合成時間比率: R_overlap = Σ[live_present ∧ game_present]Δt / T。オーバーレイが存在するフレームのみ。
- ゲーム面積占有率: A_G(t)=ゲーム由来の有効画素領域/全画面領域。mean_A_G=Σ A_G(t)Δt/T。
- 実写面積占有率: A_L(t) も同様。ただし半透明合成で表面画素の識別が曖昧な時は alphaに基づく寄与比として別記。
- ショット密度: D_cuts = (カット数−1)/T [cuts/sec]。
- 中央値ショット長: median(duration_of_shots)。
- 主題歌持続率: R_song = 歌唱／旋律が連続する時間/T。曲をBGMとして使うときは別タグ。

重要: R_L と R_G を足しても100%になるが、P_L と P_G は合計100%を超えうる。同時合成を無視して実写60%＋ゲーム60%=120%と書くのは誤りではなく、異なる定義の割合を混用することが誤り。

### 4.4 計測精度
- 映像が実際に得られた場合は、最初に放送尺／配信尺を分ける（前後の黒画面、投稿者ロゴ、CM集の継ぎ目を除く）。
- 一次アノテーションは0.25秒またはショット境界ごと。15秒CMでは推奨精度±1フレーム（入力ファイルが正しい場合）。
- YouTubeで60fps化された古い映像の補間フレームを、当時の実映像の新規カットとして計上しない。
- 2名で独立タグ付け→不一致箇所の再確認。主成分一致率および κ 係数を算出可能とする。
- 15秒版と30秒版を同じ1サンプルとして重み付けしない。番組内の実際の放映頻度が不明な場合、作品別CM素材数ベースの統計に留める。

## 5. 推奨比率モデル：史実の測定値ではない

用途: 『1990年代SFC RPGのようなオリジナルCM』の設計。15秒CM。

|模倣する構造／表現目標    |実写主体 L|合成・イラスト主体 I（実写混在あり）|ゲーム主体 G|商品・ロゴ T|狙い          |
|---------------|-----:|------------------:|------:|------:|------------|
|FFVI風／現実侵入型    |35%   |30%                |20%    |15%    |都市と異世界を衝突   |
|TOP風／楽曲主導型     |15%   |30%                |40%    |15%    |歌とキャラクターの世界観|
|MADARA2風／神話・漫画型|20%   |45%                |20%    |15%    |象徴性とグラフィック  |
|EST2風／実写ドラマ型   |45%   |25%                |15%    |15%    |2人の関係性で導入   |

この表は歴史的な4作品の実測比較ではない。類型名の「風」は新規映像を方向付けるもので、史実の内容や合成比率を断定しない。

- 実写面積を増やすと身体性・現代性が立ちやすい。
- ゲーム画面面積を増やすと『本当にどんな遊びなのか』の説明力が上がる。
- 同時合成面積を増やすとゲームと実写の境界が曖昧になり、幻想性が高まる。ただし情報密度の上昇により読みにくくなる。
- 15秒の初回は実写導入が中心、最後はタイトルを定着。30秒版は人物・世界・ゲームのつながりを補強する。

## 6. ミクロ分析：画角・撮影・画面内合成

### 6.1 画面アスペクト・放送技術
- 想定するテレビの表示比率: 4:3。YouTube上の再公開ファイルが16:9や黒帯付きでも、そのファイルの外形を原版の構図と同一視しない。
- 日本のアナログNTSC系: 約59.94 field/s、29.97 frame/s相当のインターレース映像が技術的参照。原撮影素材がフィルム、ビデオ、アニメなど何であったかはCMごとの要確認事項。
- 現代の作業用マスター例: 1440×1080 progressive, 4:3, 29.97fps。放送考証版では最終段で適切なインターレース／アナログ信号劣化をシミュレートする。
- 720×480 などBT.601系デジタルサンプル数は当時の画面が720×480ピクセルで描かれていたという意味ではない。4:3は画素縦横比・表示方法と組み合わせて扱う。
- 実ゲーム画面: SFCは表示モードで解像度が異なる。原ゲーム素材のピクセル格子は保持し、動画全体の解像度と混同しない。

### 6.2 カメラの設計項目

|要素   |検査すべきもの     |制作時の推奨（D）                   |
|-----|------------|----------------------------|
|画角   |全景／中景／アップの順序|最初に都市／場のロングを置き、2〜4秒以内に異物を見せる|
|カメラ高 |被写体に対する仰角   |巨大な造形物では軽いローアングル            |
|レンズ  |望遠の圧縮か広角の遠近か|実写プレートと合成物の消失点を一致           |
|被写界深度|背景と人物のフォーカス |背景もある程度読める、過剰な現代風の薄いボケを避ける  |
|露光   |肌と合成物のトーン一致 |曇天・逆光でも存在感を優先               |
|手ブレ  |素材の固定／揺れ    |VFX用プレートでは過剰な揺れを避ける         |

### 6.3 合成方式の選択
1. カット接続: 実写全画面 → ゲーム全画面。最も明瞭。合成なしで時代感を構築可能。
2. 枠内合成: 実写のテレビ・看板・窓などにゲーム画面を貼り付ける。カメラトラッキングとパース変形が必要。
3. キーイング／マット: クロマキーで撮った俳優や造形物を背景に配置。輪郭の色かぶり、接地影、粒状感を調整。
4. 実写と絵の重ね合わせ: フェード／マルチプレーン／ディゾルブ。重ね時間を長くし過ぎると視覚情報が飽和。
5. ピクセルキャラの現実侵入: 必ずしも当時のCMの実際の方式ではないが、現代の独自解釈として有効。ピクセル境界を保持し、背景の動きと合成レイヤーのブレを一致させる。

### 6.4 合成レイヤー構成（制作向け）

```
V8  放送用ノイズ／アナログ伝送シミュレーション（最終工程のみ）
V7  製品名・コピー・発売日・機種ロゴ
V6  画面フラッシュ／ワイプ／光学的トランジション
V5  ゲーム映像（フルフレームまたは変形した小窓）
V4  CG／イラスト／平面スプライト
V3  被写体（実写人物・セット・造形物／必要ならロトスコープ）
V2  接地影・反射・大気・煙
V1  実写背景プレート
A4  ナレーション／タイトルコール
A3  環境音・VFX・ゲームSE
A2  主題歌／編曲／BGM
A1  収録基礎音
```

実際のオクルージョンに応じて前後関係を入れ替える。レイヤー図は制作推奨モデルであり1994年の編集台や機材構成の復元ではない。

### 6.5 カラー／質感
- 実写：やや軟らかなハイライト、多少のクロマ・ブリード、過剰でない映像ノイズ。色彩の再現は年代風エフェクトの推奨であり全CMの共通史実ではない。
- ゲーム：輪郭・ドットの明瞭さを維持。写真側のブラーをゲームスプライトに均等適用しない。
- テロップ：明度差・太い縁取り・影・中央配置などで低解像度表示でも可読性を優先。
- レターボックス：オリジナル4:3に不要な映画風上下黒帯を後付けしない。
- 現代的レンズフレア、カメラシェイク、超浅い被写界深度、過度の粒子ノイズは**『90年代らしい』と混同しやすい後付け記号**。参照映像の有無を逐一確認する。

## 7. 音響・編集リズム

### 7.1 音の4レイヤー
1. 主題歌／メインテーマ: 世界観と長期記憶を担う。FFVIやTOPやMADARA2で音楽が重要だったという文献があるが、各CMの具体的ミックス量は未測定。
2. 現場環境音: 人混み、風、遠い交通音等。実写の『ここにいる』感覚。
3. ゲーム的SE: 決定音、魔法、衝突音、遷移音。画面が2Dへ転換するときの接続装置。
4. ナレーション／ロゴ: タイトルを最後に記憶させる。

### 7.2 15秒編集の設計原則
- 冒頭0〜2秒：ひとつの強い視覚的問い。
- 中盤2〜9秒：実写と異世界の関係を見せる。
- 後半9〜13秒：ゲーム映像・キャラクター・クライマックス。
- 終端13〜15秒：タイトル・ゲーム機・必要なら公開情報。

> 秒数は新規制作の推奨案であり、実CMの編集台本を復元したものではない。

音から映像への連結: 切り替えを曲のダウンビートまたは歌詞フレーズの区切りに合わせる。ナレーションは音楽の主旋律を覆い隠し過ぎず、テレビ小型スピーカーで試聴する。

### 7.3 リズムの数式化（制作用）
- shot_duration[n] = cut_time[n+1] − cut_time[n]
- cut_onset_density(t) = 直前2秒のカット数/2
- 音楽テンポが BPM のとき、四分音符の長さ b = 60/BPM 秒。
- 15秒に含まれる拍数は 15×BPM/60。例として120 BPMなら30拍。ただし当時の作品CMが120 BPMだったという意味ではない。
- 視覚的な編集拍節を 1b, 2b, 4b の長さから選び、強いシーンは小節をまたいで保持。ジャンプカットを多用し過ぎない。

### 8.3 30秒拡張
- 0–5秒：現実の場の提示
- 5–10秒：登場人物の欲望／異変
- 10–17秒：世界の侵入・身体的リアクション
- 17–23秒：ゲーム／イラスト／体験の断片
- 23–27秒：最大の感情・音楽的高揚
- 27–30秒：ロゴ・コピー・商品

30秒版は15秒版を単に2倍に伸ばさず、感情を理解する余白とゲーム内容を保証するカットを増やす。

## 9. 分析ワークフロー：実映像が入手できたときの再現手順

1. 権利上許される方法で当時のCM映像ファイルを準備。録画元、撮影／変換時期、圧縮、投稿者、版、動画尺、放送局が分かれば記録。
2. ffprobe でフレームレート、ピクセル寸法、画素縦横比、インターレース、音声方式を確認。
3. 映像を目視し、個々のCMの正確な開始／終了を切り出す。CM集内の空白・投稿者による字幕・余白を除く。
4. ショット境界を記録。自動シーン検出は候補として利用し、フラッシュ／ワイプの誤検出を目視校正。
5. 各ショットに第1層 L/G/I/T/X と第2層の重ね合わせタグを付与。
6. 1秒に4フレーム以上サンプリングして、ゲーム画面のフレーム内面積を矩形／ポリゴンで概算。実写との接触時間や透明度は別列にする。
7. 音声の入るタイミング、歌／ナレーション／SE、画の変化点を記録。
8. 比率と平均ショット長、カット密度、同時合成率、タイトル表示秒数を算出。
9. 15秒版・30秒版・改訂版それぞれを個別集計し、作品間比較はバージョン単位の階層化を明記する。
10. 結果を「観測／算出／解釈／提案」のラベル付きで保存する。

実行例:

```
ffprobe -v error -show_entries \
  format=duration:stream=index,codec_type,width,height,r_frame_rate,avg_frame_rate,sample_aspect_ratio,field_order \
  -of json cm.mp4

# 比較用サムネイルを0.5秒間隔で生成（権利と利用目的に注意）
ffmpeg -i cm.mp4 -vf 'fps=2,scale=640:-2' frames/frame_%04d.png

# 各フレームのセグメンテーションは人手＋独自CVで確認
# 注：fps変換した画像群はショット境界の精密確定には使わない
```

### 9.1 自動検出の落とし穴
- ドット絵と実写をエッジ密度だけで分類しない。セルアニメ、文字、静止画も高エッジ密度になり得る。
- 単なるRGBヒストグラム差では暗転・閃光・画面分割を誤ってカットと判定する。
- VHS再公開やYouTube補間に起因するノイズを『当時の演出』と断定しない。
- CM中の「映像上の合成」と「ポストプロダクションで制作された合成」は別概念。1枚画面の見た目だけで機材や手法を確定しない。

## 10. 品質管理・納品仕様（現代の再制作）

### 10.1 納品候補
- マスター：4:3、1440×1080、29.97fps、プログレッシブ作業版、高ビットレート。
- 検証用：4:3、640×480、H.264/AAC。
- 追加：16:9・9:16へ切り出す場合は別コンポジションを組む。無造作に横伸ばししない。
- 保存物：ショット一覧CSV、音声キュー一覧、ソース一覧、テロップ原稿、クレジット・ライセンス管理。

### 10.2 チェックリスト
- ☐ 作品・機種・発売年・放送版を混同していない
- ☐ 4:3の形状と人物の見切れが適切
- ☐ 実写プレートと異物の光源・影・遠近が一致
- ☐ ゲーム画面のドットが縮小拡大で不自然に溶けない
- ☐ 歴史分析の値と制作推奨値を同じ表で混ぜていない
- ☐ 歌・声・SEの干渉を小型スピーカーで確認
- ☐ 最後のタイトルが初見で識別できる
- ☐ 元ゲームの映像・楽曲・ロゴ・出演者肖像の利用許諾を確認
- ☐ 現代的グレーディングが『VHS感』を過剰に誇張していない
- ☐ 実際のカット単位の注釈・再現レシピが保存されている

## 13. 最終結論

90年代のSFC RPG CMの核心は、特定の合成ソフトや単純な『VHS画質』ではなく、日常の実写が持つ説得力と、ゲーム世界が持つ想像力を、15〜30秒の短い時間構造の中で往復させる映像文法にある。

本仕様は、その文法を①作品ごとに区別した史実、②時間比率・画面比率・同時合成率の計測方法、③現代の再制作レシピに分解した。定量比較表を史実として完成させるには、上記CM動画のファイルまたはショット・スクリーンショットの実測が必要である。
