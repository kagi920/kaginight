# 仕様書：90年代スーパーファミコンCMの実写の使い方 — 解析と再現の設計図

作成：2026-11-10（Muse）
範囲：1990〜1996年のスーパーファミコン（本体＋ソフト）のテレビCM。人気作・代表作を中心に、実写の使われ方をミクロ（1本ごと）とマクロ（全体）で解析し、最後に同じ作りを再現するための設計図を付ける。
区分：出典のある事実／当時を知る者の回想・推察／調べた範囲で分からなかった。
注意：CMの秒数配分を実測した資料は存在しない。本書の「比率」は、尺と構成要素からの定性的な配分であり、秒数実測ではない（8章参照）。

## 1. 目的（1行）

90年代のスーパーファミコンCMで「実写がどう被っていたか」を、型と比率で掴み、同じ作りを今の映像制作で再現できる形にする。

## 2. 結論の要約

- 実写は脇役ではなく、看板タイトルで主役だった。ゲーム画面を一切出さない全編実写のCMが、任天堂の看板RPG（ゼルダ）、カプコンの看板格闘（ストII）、任天堂の看板RPG（MOTHER2）で実際に放送された。
- 実写の入り方には再現可能な型がある。本書では7つの型に分けた（3章）。比率の目安は型ごとに決まっている（実写100%／実写リードの融合／実写ゼロの対照群）。
- 「実写 → CG に置き換わった」という単線の歴史は資料と合わない。プレイステーションのCG路線が生まれた同時期に、せがた三四郎・湯川専務というタレント実写が最大の話題作になった。実像は併走。
- なぜ実写だったのか、制作側の一次証言は確認できなかった。裏付けのある説明は「ゲーム画面だけだと味気ない、アニメを作るのは手間がかかる、ゆえに実写」という当時を知る者の推察まで。

## 3. 実写の型（分類）

| 型 | 名前 | 定義 | 実写の比率の目安 | 代表作 |
|---|---|---|---|---|
| A | 全編・キャラ扮装 | キャラに扮した人間だけで構成し、ゲーム画面を出さない | 実写100% | ゼルダ神々のトライフォース（1991）、ストリートファイターII（1992） |
| B | 全編・タレント素顔 | タレント本人の実写ドラマで、ゲームの内容に触れない | 実写100% | MOTHER2（1994、木村拓哉） |
| C | 実写フック＋ゲーム画面 | 冒頭の実写で掴み、後半はゲーム画面で紹介する | 実写が冒頭の山場、残りは画面 | FFVI 日本版（1994） |
| D | 実写と画面の交互融合 | 実写のアクションと必殺技などのゲーム映像を切り替えて融合 | 実写と画面が交互 | 餓狼伝説スペシャル（1993） |
| E | パペット・着ぐるみ・人形 | 人間ではなく人形系の実物でキャラを立てる | 実物パートが主役 | FFVI 北米版（モグのパペット）、スーパーメトロイド（人形アニメとの合成） |
| F | 声・歌だけの型 | 映像は画面やアニメで、声や歌の演出だけで記憶を作る | 実写なし | エストポリス伝記II（1995）、テイルズ オブ ファンタジア（1995） |
| G | 実写ゼロ（対照群） | CGやゲーム画面そのものが売りで実写を使わない | 実写0% | スーパードンキーコング（1994、プリレンダーCG） |

参考：ドラクエシリーズにはファンWikiによる6分類（ダイジェスト型／ドラマ型／プレイヤー型／有名芸能人起用型／ハード告知型／その他）が実在し、「実写＋ゲーム画面の形式が多い」と総括されている。本書の型C・D・Bとおおむね対応する。

## 4. ミクロ解析（1本ごと）

### 4.1 ゼルダの伝説 神々のトライフォース（1991、任天堂）— 型A
- 構成：全編実写のダンスCM。ゲーム画面は一切なし。囚われたゼルダ姫をリンクが助けに来る設定で、スチャダラパー「ゲームボーイズ」のリズムに本作用の歌詞を乗せた「出る出る〜ゼルダの伝説♪」に合わせて集団で踊る。発売後は歌詞が「出た出た〜」に変わった版。ガノンは巨大なパペットで登場し、対決もダンスで押し切る。
- 尺：30秒版と60秒版の両説があり確定できない。
- 出演・制作：リンク役はオーディションで選ばれた16歳の女子高校生（「ボーイッシュな女の子の方がいい」という判断で女性を起用。最終選考には TOKIO 結成前の長瀬智也が残った）。ゼルダ役は新島弥生。プロデューサー倉恒良彰、監督・金巻康朗。ガノンの人形は3体作られた。
- 訂正：振付がトラヴィス・ペインという説は、日英の出典で確認できなかった。
- 読み：RPGの世界観を「説明」せず、キャラの扮装と歌と踊りの勢いだけで「祭り」として提示する型。情報量はゼロに近く、記憶への残り方を優先している。

### 4.2 ストリートファイターII（1992、カプコン）— 型A
- 構成：俳優による全編実写。ゲーム画面なし。「ハードの性能を見せるためゲーム画面をふんだんに使ったCMが多かった中、ただキャラに扮した人間のみのCMは斬新」と評された。
- 出演：リュウ役 RYO、春麗役 水野美紀（当時新人・高校生）、ベガ役 軍司眞人。キャッチコピーは「俺より強いヤツに会いに行く。」。CMソングは筋肉少女帯「バトル野郎〜100万人の兄貴〜」。
- 裏話：ロサンゼルスまでロケに行ったことを、水野美紀本人が後年の動画で語っている。
- 続編：『II' TURBO』（1993）のCMも実写で、ロケはタイ・バンコク。ガイル役ジェフ・ライベングッド。
- 読み：格闘ゲームは「人間の体」がそのまま商品の核なので、扮装した人間の存在感がゲーム画面より強い訴求になる。型Aが格闘に集中する理由。

### 4.3 MOTHER2（1994、任天堂）— 型B
- 構成：30秒スポット3タイプ。いずれもゲームの内容にはほぼ触れない。木村拓哉と喫茶店でのやりとりを見せる実写ドラマ仕立てで、周囲の客が突然「マザ〜ツ〜」と合唱を始める場面が知られる。
- キャッチコピー：「大人も子供も、おねーさんも。」（糸井重里の広告コピーの作法）。
- 読み：ゲーム画面もキャラ扮装も捨て、「このゲームは大人が買ってもいい」という空気だけを売る型。タレントの素顔の実写が、子供向けという先入観への解除装置になっている。

### 4.4 ファイナルファンタジーVI（1994、スクウェア）— 型C／型E
- 日本版：渋谷109が見えるスクランブル交差点に、天野喜孝デザインの実写ティナと魔導アーマーが突如出現し、群衆が恐れおののく。後半は本編のイベントシーンをキャッチフレーズ「夢じゃない」と共に紹介する。
- 北米版（Final Fantasy III）：モーグリのモグのパペットがモンスターのオーディションを行い、気に入らない相手を雷で落として「Next!」と叫ぶ30秒CM。型E。
- 読み：型Cは「現実の風景にゲームの存在が侵入する」構図。実写の日常（渋谷）× 異物（魔導アーマー）の落差がそのまま「夢じゃない」というコピーの意味になる。実写は世界の側を担当し、ゲーム画面は物語の側を担当する分業。

### 4.5 餓狼伝説スペシャル（1993、SNK／NEOGEO）— 型D
- 構成：テリー編・アンディ編・ジョー編の3種、60秒版が基本（30秒・15秒版あり）。香港風の雑踏や瓦礫を舞台に、キャラを模した俳優がアクションする実写パートと、必殺技を映すゲーム映像を融合させ、クライマックスはギースが必殺技で吹き飛ばされる。コピーは「100MEGA SHOCK!」。
- SNK 全体：「CMはほとんど実写版でした」という回想がある。『餓狼伝説3』（1995）のCMも実写。
- 読み：実写の打撃 → ゲームの必殺技、という因果でつなぐ編集。実写が「予告編」、ゲーム画面が「答え」になる。

### 4.6 テイルズ オブ ファンタジア（1995、ナムコ）— 型F
- 主題歌「夢は終わらない 〜こぼれ落ちる時の雫〜」を前面に使ったCMで知られる。RPGのオープニングにボーカル主題歌があること自体が当時の話題だった。歌は SFC 版が吉田由香里（PS 版以降は よーみ）。
- 構成は歌を軸にアニメ映像／ゲーム画面を組み合わせたものという記述があるが、出典は個人サイトで信頼性は限定的。実写の要素は確認できない。
- 読み：実写の代わりに「歌」が感情の実在感を担う型。後のアニメ・ゲームCMの主題歌路線の先駆け。

### 4.7 エストポリス伝記II（1995、タイトー）— 型F
- 15秒。セランとマキシムが互いの名前を「セラン…マキシム…」と次第に強く呼び合う、声の演出だけで構成されるCM。実写の要素は確認できない。
- 初代（1993）のキャッチコピーは「これは単なるファンタジーRPGではない」。CM の形式の詳細は確認できない。
- 読み：15秒という最小の枠で、映像の情報量を捨てて「声と名前」だけに絞る型。実写が担っていた「人の実在感」を声だけで代替している。

### 4.8 魍魎戦記MADARA2（1993、コナミ）— 型は未確定
- CMソング「Lights〜遥かなる旅立ち〜」（歌：國府田マリ子）がテレビCMソングとして記録されている。
- 見た者の回想では「闇夜で燃える家、剣を持った人物、寂しそうな歌」で、明るさのない雰囲気重視のCM。ゲーム画面中心ではなかったことがうかがえるが、映像が実写かどうかの明記は出典になく。

### 4.9 対照群と周辺の実例
- スーパードンキーコング（1994、任天堂）— 型G：プリレンダーCGの映像そのものが最大の売りで、「今までのテレビゲームでは表現できなかったコンピューターグラフィックス」と訴求。実写の要素は確認できない。実写が「凄さ」の担当だった時期に、CGがその座を奪う転換点。
- FFIV（1991、スクウェア）：笑い声とチョコボのテーマをバックにダチョウが海岸を走り抜ける実写CM。ゲーム内容とは無関係のシュールなインパクト型。型の分類では「実写の異物」として型Cの変形。
- スーパーメトロイド（1994、任天堂）— 型E／③：実写俳優によるドラマパートと人形アニメーションの合成。
- スーパーマリオワールド（1990、任天堂）：三波春夫「世界の国からこんにちは」の替え歌に乗せた30秒。映像は粘土細工の世界（ストップモーション）とゲーム画面とみられる。**着ぐるみの実写マリオは確認できなかった**。なお1991年のキリンレモンCMでは田中律子がマリオに扮しており、型Aの実例だがゲーム本体のCMではない。
- サテラビュー（1995、任天堂）：30秒。宇宙服を着たマリオ（アニメ）が仕組みを説明し、タモリ・内田有紀らパーソナリティは放送番組の出演者として告知される。タレントがCM映像自体に出演したかは確認できない。テレビCM自体は約1か月しか流れなかった。
- ドラゴンクエストV（1992、エニックス）：「スタッフロール＆実写」という記録あり。実写部分の具体的な内容は確認できない。DQIII の SFC リメイク版CMでは実写で勇者・武闘家・盗賊・魔法使いが登場した（型A）。シリーズ全体では「実写＋ゲーム画面の形式が多い」。

## 5. マクロ解析

### 5.1 年代の推移
- 1990〜91：主流はゲーム画面中心。スーパーファミコンの売りはモード7の回転・拡大・縮小で、初期タイトルは新機能の訴求が中心だった。ただし実写の例外は初期からある（ゼルダ 1991、FFIV 1991）。
- 1992〜94：格闘ゲームを軸にキャラ扮装の実写が本格化（ストII、餓狼伝説）。RPGでは実写フック型（FFVI）やタレント型（MOTHER2）が出る。
- 1994〜95：プレイステーション（1994年12月発売）が3Dポリゴンを前面に出し、CG路線が生まれる。ドンキーコングのプリレンダーCGも同時期。
- 1995以降：実写は消えず、タレント実写が系譜として強化される。せがた三四郎（セガサターン、1997〜98、全19本、藤岡弘、）と湯川専務（ドリームキャスト、1998、全8本、ACC全日本CMフェスティバルの最優秀テレビCM賞）は90年代後半の最大の話題作で、どちらも実写。
- 結論：推移は「画面 → 実写 → CG」の置き換えではなく、「画面中心の主流に、実写の実験が混ざり、後にCGが加わって三つが併走する」形。

### 5.2 メーカー別の癖
- 任天堂：看板タイトルで大胆な実写実験をした（ゼルダの全編ダンス、MOTHER2のタレントドラマ）。近年型の「誰かが遊んでいる様子を見せるCM」とは対照的、という回顧がある。サテラビューではパーソナリティ起用を販促の核にした。
- カプコン：「何かと実写化が好き」と評される。ストII（ロサンゼルスロケ）→ TURBO（バンコクロケ）→ ハリウッド実写映画（1994）と実写展開を繰り返し、同時期にアニメ映画も持つ両路線型。
- SNK：CMはほとんど実写という回想。海外キャスト＋海外の風景で「世界の格闘」の空気を作る。
- エニックス：シリーズを通じて「実写＋ゲーム画面」が定番で、SFC版 DQ5 から外国人俳優の起用が定番化した。
- スクウェア：FFIV のダチョウ、FFVI の渋谷への侵入と、ゲーム内容と切り離した「異物」のインパクト型が目立つ。メーカー全体の作風として体系立てた記述は確認できない。
- セガ（90年代後半）：キャラを立てるタレント実写が看板になった（5.1参照）。

### 5.3 なぜ実写だったのか（証拠の格を分けて）
- 「ゲーム画面だけだと味気ない、アニメを作るのは手間がかかる、ゆえに実写になっていたのかな」（当時を知る視聴者の推察として明記された文章）。
- ストII のロサンゼルスロケについて「不景気のなり始めと言われる時代ながら、まだまだテレビの世界は湯水の様にお金が使えていた」という当時の空気の回顧（出演者の回想を紹介する記事内）。
- 総広告費は1991年の5兆7,261億円が成長期の頂点で、1992年から停滞期に入る。ただし地上波テレビ広告費のピークは2000年で、90年代を通じて高水準を保った（電通「日本の広告費」）。つまり「バブル崩壊でテレビCMの予算が消えた」という図式は数字と合わない。
- 広告会社やメーカー宣伝部が「なぜ実写を選んだか」を述べた一次証言。個別CMの制作費の公表値。当時のゲームCMの出稿量の統計。（※原文では「分からなかった」区分の列挙とみられる）
- 構造の読み（本書の解析）：当時のゲーム画面は、テレビCMの15〜30秒で「凄さ」を伝えるには解像度も動きも足りなかった。実写の人間は、①キャラの存在感 ②笑いや驚きの感情 ③「現実に起きている」という実在感 を即時に出せる。アニメはその代替になりうるが制作の時間と費用がかかる。実写はこの3点を最速で出す手段だった、というのが回顧と事例の積み重ねから読める線である（一次証言ではない）。

### 5.4 市場の数字
- スーパーファミコン出荷：日本1,717万台、全世界4,910万台。ソフトは全世界3億7,906万本。
- 代表ソフトの国内出荷（CESAゲーム白書2000の転記）：スーパーマリオカート382万本、ドラクエVI 320万本、スーパードンキーコング298万本、ストII 288万本、ドラクエV 280万本、FFVI 255万本、クロノ・トリガー203万本、ゼルダ神々のトライフォース116万本。
- CMと売上の因果を示す資料は無い。本数は「そのCMがどれだけの市場に流れたか」の目安としてのみ使う。
