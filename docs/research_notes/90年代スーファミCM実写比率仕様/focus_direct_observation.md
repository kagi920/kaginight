# 重点4作品：原寸サムネイルの直接観察記録

- 観察者：本セッションの主担当（分類担当とは別）。2026-11-10。
- 方法：YouTube に個別投稿されたCM動画の公開自動サムネイル（hq1/hq2/hq3.jpg、480×360）を原寸で目視。各動画のおよそ 25%・50%・75% 地点とされる3点（位置は通説であり公式仕様としては未確認）。**動画そのものは再生していない**（再生ページはボット判定で読めず、回避は行っていない）。したがって以下は「その3点に何が映っていたか」の観察であり、カット割り・秒数・音声の記録ではない。
- 行番号（#）は `measurement/corpus.tsv` の `no`。動画IDは同ファイル参照。
- 証拠区分：**観察**＝画面で直接見たもの／**判読**＝画面内の文字を読んだもの／**推定**＝観察からの解釈。

## 5. 4作品に共通して観察できたこと

1. **実写は4作品すべてに含まれる。** ただし性質が違う：FFVI＝都市のロケと造形物の合成、MADARA2＝炎のロケと人物シルエット、エストポリスII＝衣装の男女と合成背景、テイルズ＝自然風景のみ（人物なし）。
2. **ゲーム画面は少ない。** 3点×複数投稿のうち、ゲーム画面が映ったのは FFVI 2点、MADARA2 1点、テイルズ 3点、エストポリス 0点。
3. **文字の役割が大きい。** 社名ロゴ（KONAMI は左上に常時、namco は冒頭の実写に重ねる、SQUARESOFT と TAITO は末尾のカード）、クレジット（歌手、音楽、キャラクターデザイナー、声優）、発売告知（「4・2 SAT」「12月15日発売」「'93年6月登場」「6月25日新発売」「好評発売中」）、商標注記（「スーパーファミコンは任天堂の商標です。」）。
4. **約75%地点はカードが多い。** タイトルロゴ、パッケージ、社名ロゴのいずれか。
5. **スーパーファミコンのロゴ**は、冒頭の画の隅（FFVI のマンホール接写の右下）か、タイトルカードの左上（エストポリス）に小さく入る。
