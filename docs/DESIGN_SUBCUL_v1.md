# サブカル層 30% 設計書 v1（2026-10-15、プレビュー v22）

依頼: 「基本デザインに、30% くらいサブカル要素を足して掛け算できるか。クラゲも含めて全体に」。
作法: 自己流で決めず、配色比率の定石・日本のサブカル視覚文化の参照・鍵山自身の系譜から要素を取り、プレビュー URL で鍵山が見てから本番に入れる。

## 1. 「30%」の置き方 — 60-30-10 の法則
UI・インテリア・グラフィックで使われる配色比率の定石。基調 60%（背景・大面積）、従属 30%（カード・見出し・主要要素）、強調 10%（ボタンなど）。鍵山の「30%」を**従属層**として実装する。基調（黒い夜とクラゲ）はそのまま、強調（金の鍵）もそのまま、その間の層をサブカルに差し替える。
出典: [UX Planet](https://uxplanet.org/the-60-30-10-rule-a-foolproof-way-to-choose-colors-for-your-ui-design-d15625e56d25)、[LogRocket](https://blog.logrocket.com/ux-design/60-30-10-rule)、[Pixpa](https://www.pixpa.com/blog/60-30-10-rule-in-web-design)（いずれも実務記事。研究ではなく経験則）。

## 3. 実装（変更点はすべて `tools/build_subcul.py` の置換で生成。手で 2 回書かない）
### 3-1 トークン（CSS 変数）
`--mix:.3`（層の強さ 0〜1）、`--sub:#e8432e`、`--sub-ink:#d7321f`、`--f-sub: Shippori Mincho B1`、`--f-dot: DotGothic16`。
コントラスト（WCAG 2 の計算値）: `#e8432e` は背景 `#07070b` に対し 5.05:1（AA 合格）、`#d7321f` の上の白文字は 4.81:1（AA 合格）。

### 3-2 画面に足したもの（UI、クラゲの上に重ねない）
- 網点レイヤー `.tone`（3px ピッチ、overlay、不透明度 = mix×0.42）と粒子 `.grain`（SVG ノイズ、screen、mix×0.22）。どちらも静止画像なので毎フレームの負荷なし。UI は `z-index:2` で上。
- 判子「夜」、縦書き一文、見出しと小見出しの書体、`.bar` の朱、ドックの角丸を 6px に、SOUND／ヒント／版番号をドット書体に。
- `prefers-reduced-motion` ではテクスチャを消す。380px 以下では縦書きを消す。

### 3-3 クラゲ（全体に掛ける部分）
コンポジット シェーダーの最終段で、ACES 後の色 `c` から
- 墨 `(0.03,0.02,0.035)` → 朱 `(0.91,0.27,0.18)` → 紙 `(0.99,0.95,0.87)` の 2 色刷り `tone` を、
- 画面座標の 45 度回転格子（ピッチ 4.5px×DPR）で輝度に応じた網点径にして作り、
- `mix(c, tone, uMix)` で混ぜる（uMix = 0.3）。
形・動き・音との同期（鐘の収縮でキック、タップでスネア）は一切触っていない。uMix=0 で v21 と同一の絵に戻る。

### 3-4 強さの比較
URL の `?mix=` で 0〜1 を指定できる（例: `?mix=0.2`、`?mix=0.4`）。右下の版番号に反映される。

## 5. 公開の手順（鍵山の OK 後）
1. `tools/build_subcul.py` の出力先を `index.html` に変え、版番号を v22 に、`noindex` を外す。
2. BASE 版（`kn-` 接頭辞）にも同じ置換を掛け、貼り付けページを再生成。
3. `og.png` を新しい見た目で撮り直す。
4. CHANGELOG に v22 を追記し、Actions の success を確認。

## 6. 鍵山が決めること

## 7. プレビュー B（2026-10-15、鍵山「30% では何が変わったか分からない。50% に」への対応）
原因: 30% を色と質感（細かい網点・薄い朱）だけで置いたため、スマホでは差が見えなかった。50% にするだけでなく、一目で分かる**構造物**を足した。
- 朱の帯（ポスターの斜め帯）「XR DRUMMER ── 叩く人として参加できる」
- 右端の大きな縦書き「鍵山喬一の夜」（昭和活字系明朝）
- 電光掲示の流れる一行（ドット書体、クラゲの下）。`prefers-reduced-motion` では止まる
- 題字に朱の落ち影、肩書を朱の面に白抜き、ドック・ボタン・シートに朱の枠と版ずれ風の影
- 網点を 5px ピッチに粗くし、クラゲ側の網点も 6.5px×DPR に。7 秒に一度 0.14 秒だけ版ずれが大きくなる
- `mix-blend-mode` は外した（キャンバス上の合成負荷）。フレーム時間は v21 比 +2%（346 vs 340 ms、ソフトウェア GL）
既定 `?mix=0.5`。0.3 と比べたいときは `?mix=0.3`。

## 8. 方向 C（2026-10-15、鍵山「50% は方向が違う。昭和・アーバンギャルドに寄せない。アートポップ寄りのサブカル。塩田千春の要素、赤い糸のクラゲがたまに飛ぶ。元の内容はしっかり残して 30%」への対応）
B の帯・判子・電光掲示・ドット書体・網点は全部外した（昭和サブカルの系統だったため）。参照を取り直す。

| 参照 | 何を取るか | 実装 |
|---|---|---|
| 塩田千春の赤い糸のインスタレーション（糸の網、《掌の鍵》2015 ヴェネツィア：赤い糸と鍵） | 「糸でつながる」こと。KAGI NIGHT の「鍵」と「人がつながる夜」に直結 | ① 画面の縁から中央へ渡る赤い糸の網（SVG、22 本、結び目 3 つ、静止）② 群れのうち 2 体を**赤い糸のクラゲ**として描く（傘は糸の束、触手 20 本と口腕 4 本は糸、点は薄く残す）。たまに画面を横切る |
| アートポップ（単純な形・一色の強いアクセント・余白） | 朱を「小さく、効く場所にだけ」 | 肩書・小見出し・強調語・主ボタン・開いているタブ・スライダーだけ朱。書体は元のまま |
| 赤の階調 | 影を赤黒へ寄せる軽いグレード（網点なし） | 最終合成で duotone を mix×0.6（=18%）だけ混ぜる |

- 言葉は一切足していない（B で足した縦書き・帯・電光掲示の文は削除）。
- ヒーローの形・動き・音は不変。`?mix=0` で v21 と同一。
- 検証（390×844、swiftshader）: JS エラー 0、糸 22 本・結び目 3、フレーム時間 345 ms（v21 340、+1.5%）。

### いつも守っていること（鍵山の指示の要約。設計はここから外れない）
1. 自己流で決めない。専門家の作法と参照（作家・定石・公式資料）から取り、出典を書く。
2. 元の内容（クラゲ・音・5 つの扉・文章）を壊さない。足すものはクラゲに合わせる。
3. 言葉を新しく作らない。HP にある文だけを使う。価格・機材・技術の話を書かない。「計算機」と書かない。
4. 鍵山ソロのみ。他人の顔・名前・作品を使わない。
5. 本番は鍵山の OK 後。プレビュー URL と版番号で確認してもらう。
6. push 先は kagi920/kaginight だけ。

## 9. 位置づけの変更（2026-10-15、鍵山）
方向 C（サブカル 30%、赤い糸）は**ライブのときのスキン**として保存する。本番の既定はこれまでどおり元の HP。ライブやイベントのときに、その夜の色に合わせて演出を切り替える（サブカル 30%／120%、ポップなど）。時間帯で少し変える案もある。実装（切替の仕組み）はライブ日程が決まった時点で行う。

## 10. KAGI スキン（2026-10-15、鍵山「30% はやめて 120%。ドアの鍵（鍵山のアイコン）を足す。1 時間のうち 10 分だけそれに変わる。基本はいつも通り。基本のクラゲはそのまま、モチーフを壊さない」）
- **既定はいつも通り（v21 と同一）**。毎時 **0〜9 分**だけ、2.4 秒かけて KAGI スキンに変わり、10 分に戻る。
- スキンの中身（方向 C を 120% に）: 赤い糸の網 74 本、糸の結び目から吊るした**ドアの鍵** 6 本（金 4・白 2、ゆっくり揺れる。塩田千春《掌の鍵》の参照、鍵山のアイコン）、群れの脇役は全部**赤い糸のクラゲ**、暗い水だけ赤黒へ寄せる階調、朱のアクセント。
- **主役のクラゲは一切触らない**（形・動き・色・音）。階調は明るい部分には掛からないので主役の色は保たれる。言葉は足していない。
- 確認用: `?skin=on`（常時オン）、`?skin=off`（常時オフ）、`?mix=` で強さ（0〜1.5）。
- 検証（swiftshader）: ON／OFF とも JS エラー 0。OFF は v21 と同一の絵。フレーム時間は ON で v21 より軽い〜同等（糸は線描画で点より軽い）。
- 本番 v22 に入れるのは鍵山の GO 後（`tools/build_subcul.py` の出力先を index.html に変え、版番号を v22 に、noindex を外す。BASE 版にも同じ置換）。
