# note 操作 指示書 v1（別の AI／代行者向け）

発行: 2026-10-14。発行者: 鍵山喬一（note ID kagi03）の制作担当 Claude Code。
対象: 鍵山のブラウザで note（https://note.com/kagi03）を操作する AI エージェント、または代行者。
前提: この指示書だけで作業できるように書いてある。不明点は推測せず、鍵山に確認する。

---

## 0. 最初に守ること（禁則）

1. **お金が動く操作をしない**。有料記事の価格設定・変更、メンバーシップのプラン作成・価格変更、購入、課金、口座情報の変更は、鍵山が自分で行う。画面まで案内してよいが、確定ボタンは押さない。
2. **削除しない**。記事、下書き、マガジン、コメント、フォロー、画像を削除しない。非公開化もしない。
3. **投稿・公開は、鍵山が「公開して」と言った原稿だけ**。自分で文章を作って公開しない。文言の変更も勝手にしない。
4. **書いてはいけないこと**: 他の出演者・メンバーの名前や顔、鍵山の職や収入や健康などの私的情報、visualgate-livesystem の成果（XR_DRUM、GHOST RACK、Scratch Box）を鍵山の制作物として書くこと、存在しない価格、機種限定の言い方（「iPhone で」「Safari で」）。
5. **ログイン情報を保存・転送しない**。パスワードや認証コードを文章に書かない。
6. 作業の記録は「やったこと／見たもの／できなかったこと」を分けて報告する。「伝えた」「できた」は実際に画面で確認したものだけに使う。

## 1. 作業 A: いま note にあるものを全部書き出す（最優先）

目的: 制作担当（Claude Code）は note に接続できない。既存の内容をテキストで受け取る必要がある。

手順
1. https://note.com/kagi03 を開く。
2. プロフィール欄の文章を全文コピー。
3. 公開中の記事を一覧にする: タイトル、URL、公開日、無料/有料、価格、スキ数、ビュー数（ダッシュボードで見える範囲）。
4. 各記事の本文を全文コピー（有料記事は有料部分も。鍵山本人のアカウントなら全文見える）。画像は「ここに画像（内容の説明）」と書く。
5. 下書きがあれば同様に。
6. マガジン、メンバーシップ（プラン名・価格・加入者数）、固定記事の有無を書き出す。
7. 設定 → 「有料コンテンツの販売」「メンバーシップ」が有効か、売上の受取口座が登録済みかを確認（画面の表示だけ。入力はしない）。
8. 以上を 1 つのテキストファイル `note_export_YYYYMMDD.md` にまとめ、鍵山に渡す。鍵山がそれを制作担当に貼る。

報告の型
```
## 記事 1
- タイトル:
- URL:
- 公開日:
- 無料/有料（価格）:
- 数字（ビュー/スキ/購入）:
- 本文:
（全文）
```

## 3. 作業 C: マガジンを 3 本作る（鍵山の承認後）

名前と説明。価格は付けない（無料マガジン）。
1. 「KAGI NIGHT 制作ログ」— 自作の演奏システムを作る途中の記録。

既存記事があれば、内容に合うマガジンに追加する。迷ったら追加しないで報告。

## 4. 作業 D: 原稿の公開（原稿が届いてから）

制作担当が書いた原稿は、ファイル名 `NOTE_xx_タイトル.md` で鍵山から渡される。各原稿の先頭に次の指定がある。

```
公開指定:
- タイトル:
- マガジン:
- 無料 / 有料（価格は鍵山が入力）
- 有料ラインの位置: 「■ここから有料■」の行
- 見出し画像: 鍵山から受け取る
- 固定記事にするか: する / しない
- ハッシュタグ:
```

手順
1. note の「投稿」→「テキスト」。
2. タイトルと本文を貼る。見出し（##）は note の見出しに変換する。
3. 「■ここから有料■」の行の位置に有料ラインを置き、その行自体は削除する。
4. 価格欄は空のままにし、鍵山を呼んで入力してもらう（禁則 1）。
5. ハッシュタグを付ける。マガジンに追加する。
6. 「公開」は鍵山が押す。押す前にプレビューを鍵山に見せる。
7. 公開後、URL をコピーして報告。

## 5. 作業 E: 週 1 回の計測（毎週同じ曜日）

ダッシュボードから次を記録し、鍵山に渡す。
| 日付 | 記事 | ビュー | スキ | コメント | 購入数 | 売上 | フォロワー総数 |

数字を推測しない。見えない項目は「見えない」と書く。
