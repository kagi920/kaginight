## リリース手順（毎回同じ）
1. `VERSION` を 1 上げる → 両ページに版番号を焼き込む → BASE 全文と貼り付けページを再生成。
2. 検査：ブロックタグ数一致、必須タグ、JS エラー 0、連続フレーム確認。
3. `main` に push → GitHub Pages のデプロイ成功を確認。
4. 鍵山：独自 HP を開き直して右下の版番号を見る。BASE は貼り付けページから全文を貼り直し、プレビューの右下で版番号を見る。
5. 版番号が古ければキャッシュ。タブを閉じて開き直すか URL 末尾に `?v=番号` を付ける。

## v23（2026-10-15）— 合図が反応しない件の修正
- 鍵山「タン・タタ・タンと押しても反応しない」。原因 2 つ: ①判定が最初の間隔を基準にしていて、親指の一打がずれると全部外れる ②応えたときの変化が普通の一打と区別できない（群れは画面外、鍵の輪が薄すぎ）。
- 判定: テンポを最小二乗で推定し、許容 ±35%、テンポ 200〜1600 ms。`?knock=1` を付けると右下に叩いた比が出る（調整用）。
- 応え: 叩き終えて 0.55 秒、夜全体が息を止める（全点が 12% まで暗くなり、音も止まる）→ 群れ全部が同時に一打、レンズが大きく開く、SOUND が ON ならキック＋一打。鍵の外側の輪をはっきり見える太さに（文字なし）。
- 検証: JS エラー 0。判定 7 パターン（正しい比・多少のずれ・速い・遅い→応答、均等・ずれ大・短すぎ→無反応）。ボタンと画面タップの両方で叩打が数えられること。息止め→応答→輪の表示。BASE 版はブロック開閉一致、必須タグあり、貼り付けページの往復一致。
